Privacy policy

How Tab Sunset List handles your data

Effective September 6, 2026

The extension does its core job without a server or account.

Data stored by the extension

The extension stores each tagged tab’s URL, title, review date, intent, and optional note.

It also stores saved decisions and the last closed item for undo.

This information stays in your browser’s local extension storage.

Network use

The extension does not send tab data over the web.

It has no analytics, advertising, cloud sync, or browsing-history service.

Bookmark actions use the bookmark tools built into your browser.

Browser permissions

  • Tabs: read a tab you tag, close decided tabs, and reopen the last closed URL.
  • Storage: keep your review queue and saved decisions in this browser.
  • Bookmarks: create a Tab Sunset List folder after you choose the bookmark action.
  • Alarms: refresh the due-tab badge.

Delete your data

Choose “Delete local data” in the review page to clear the queue, saved decisions, and undo record.

This action leaves browser bookmarks alone. Delete bookmarks from your browser’s bookmark manager.

This website and demo

This website sets no cookies and loads no third-party fonts or scripts.

The demo stores sample state under a separate browser-storage key.

Starting for real or resetting the demo deletes that sample state.

The site service worker caches public files so these pages remain available offline.

Contact and changes

Report a privacy issue in the public source repository (external).

Policy changes will update this date and appear in the repository history.
